Methodology · Open, use & share

Open this website in a modern browser. Reviewed holdings load first; historical holdings load only when selected. No login, tracking or external fonts. SEC links open only when clicked. Watchlists remain local to this browser and website; they are not uploaded or included when sharing a link.

Choose one evidence set and reporting date. Reviewed data covers an accepted subset, not the full market. Historical reference is retained SEC dataset detail, not independently revalidated; it is never merged with reviewed holdings. A matching name across sets is not proof of identity. Legacy derived totals, risk scores and entry/exit claims are not used.

Missing is Unknown, not zero. Complete totals require every contributing value; observed sums display their coverage. FV/principal and FV/cost use positive denominators. Benchmarks are unweighted row distributions, not transaction pricing, yields or comparable tranches. Dollar figures retain supplied units; common-currency comparability is not established. Changes in population are not returns, exits or purchases. Reported PIK does not establish distress. No operating financials or covenant conclusions are supplied.

Positions CSV includes all matching rows and reviewed exact-row changes where eligible; Table CSV follows the visible analysis and sorting, including rows beyond the first display page. Print captures the current analysis and selected borrower evidence. Use Borrower Review or Deal Intel for a focused memo.
